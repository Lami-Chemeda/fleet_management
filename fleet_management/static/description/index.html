Common Questions

Does this replace Odoo's native Fleet app?

It fully extends it. It utilizes existing fleet.vehicle models but wraps an entire operational ERP system (budgets, trips, scorecards) around them.

Is the system modular?

Absolutely. If you only want Trip Approvals and Maintenance, you can ignore the Driver Scorecard or Budgeting features. It adapts to your specific workflow.

Do external drivers need Odoo licenses?

No. The included Web Portal allows drivers to log inspections, request trips, and report incidents using free portal user accounts.
